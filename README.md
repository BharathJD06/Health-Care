## 📌 Project Overview
A healthcare analytics project examining patient records to uncover clinical trends, detect data anomalies, and apply machine learning for bias detection and fairness analysis. This project aligns with real-world co-op work at Synod Intellicare.

## 🗂️ Files
| File | Description |
|------|-------------|
| HealthCare Analysis.ipynb | Python analysis & ML notebook |
| healthcare_dataset.csv | Patient healthcare dataset |

## 🛠️ Tools & Technologies
- **Python** (Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn) — Full analysis pipeline
- **Jupyter Notebook** — Development & documentation environment

## 📊 Key Analysis
- Patient demographic distribution analysis
- Clinical outcome trend identification
- Data quality checks & missing value treatment
- Machine learning for bias detection across demographic groups
- Fairness metrics: demographic parity, equalized odds
- Feature importance analysis

## 💡 Key Insights
- Identified data inconsistencies and anomalies in 10,000+ records
- Detected demographic bias in clinical outcome predictions
- Improved fairness metrics by 15–25% through bias mitigation techniques
